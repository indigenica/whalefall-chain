# Instructions for Claude in this repository

This repository is **generated**: it is a one-way export of `indigenica/whalefall` (rules in
`paper/zenodo_whale/export/MANIFEST.txt` there; source commit and file hashes in `EXPORT_PROVENANCE.json` here).

- **Do not edit files here.** Any change must be made in whalefall and exported again with `make export-chain` from the
  whalefall root. A direct edit here is overwritten by the next export and is reported by `make check-chain` as
  "EDITADO EN DESTINO".
- To review or reproduce: `make test`, `make reproduce`, `make action`, `make numbers`, `make figures`, `make paper`
  (see `README.md`).
- The preregistrations and reports in `docs/` are the original dated records, in Spanish,
  and are never rewritten.
